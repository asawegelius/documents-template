# Solo Kanban Board Template

This template is intended for part-time solo work where Scrum ceremonies would be heavier than useful.

## Recommended Columns

- `Ideas`
- `Ready`
- `Doing`
- `Blocked`
- `Validate`
- `Done`

## Working Rules

- Keep `Doing` limited to 1 item.
- Move work to `Validate` before calling it done.
- Split large items until each card can make visible progress in one focused session.
- Mark exploratory work as `spike`.

## Suggested Card Types

- `platform`
- `product`
- `docs`
- `security`
- `spike`
- `bug`

## Suggested Card Template

### Title

Short action-oriented title

### Why

Why this matters now

### Done When

- Outcome 1
- Outcome 2

### Notes

- Links to requirements, ADRs, or use cases
